# Sales Performance Analysis (SQL + Power BI)

## 📌 Project Overview
This project analyzes retail sales data to identify revenue trends, regional performance, and product-wise insights.  
An interactive Power BI dashboard was built to support business decision-making.

## 🛠 Tools & Technologies
- SQL (SQLite / MySQL)
- Power BI
- Python (for EDA – optional)
- Excel / CSV

## 📊 Key Insights
- Identified top-performing product categories and regions
- Analyzed monthly revenue trends
- Built KPI metrics for total revenue and sales distribution

## 📈 Dashboard Features
- Total Revenue KPI Card
- Sales by Product Category (Bar Chart)
- Monthly Revenue Trend (Line Chart)

## 📂 Dataset
Retail sales dataset containing:
- Transaction ID
- Date
- Product Category
- Quantity
- Total Amount
